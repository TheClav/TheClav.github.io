# Calvin DeBellis — Personal Portfolio

My personal portfolio site, live at [theclav.github.io](https://theclav.github.io).

## About

A dark-themed static portfolio built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step — just clean, fast, and fully responsive.

## Sections

- **About** — Background, education, location, and interests
- **Projects** — Featured work including the TrickSki Calculator, Trickski Orientation CNN, MiniSpark Engine, and Spark Cluster Project
- **Experience** — Internship timeline (Ataccama, Instructure, Inspirit AI)
- **Testimonials** — Recommendations from past managers and mentors
- **Contact** — Click-to-copy email, GitHub, and LinkedIn links

## Features

- Animated side navigation with scroll progress tracking
- Expandable testimonial cards
- Live indicator pill button with animated pulse
- Click-to-copy email button
- Scroll-triggered fade-in animations
- Fully responsive with mobile hamburger nav

HTML · CSS · JavaScript
